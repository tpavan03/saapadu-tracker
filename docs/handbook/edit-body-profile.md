# Edit body measurements and routine

Open **More**, find your profile card, and choose **Edit**. The form includes name, current weight, height, age, goal weight, usual activity and the body reference used by the calorie equation. Review all measurements before saving; the form uses kilograms and centimetres rather than guessing units from the number entered.

Changing current weight also creates or corrects today's weigh-in. To enter a reading from a previous date, use the dated check-in screen instead. Editing age updates the stored birth-year approximation; it does not collect a full date of birth.

Activity and daily movement credit affect the calculation path, so choose them to describe the intended routine. A saved measurement refreshes the current recommendation while past diary targets retain their snapshots. The result remains an estimate, not a measured metabolic test.
